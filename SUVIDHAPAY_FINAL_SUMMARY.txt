🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════

  Development Setup:
  ─────────────────
    1. Start PostgreSQL:
       docker-compose -f docker-compose.dev.yml up -d

    2. Terminal 1 - Backend:
       cd SuvidhaPay-api
       npm install
       npm run migrate
       npm run seed
       npm run dev

    3. Terminal 2 - Frontend:
       cd SuvidhaPay-web
       npm install
       npm run dev

    4. Access:
       Frontend: http://localhost:3000
       API:      http://localhost:3001
       Database: localhost:5432

  Production Deployment:
  ─────────────────────
    1. Configure .env:
       cp .env.example .env
       # Edit with your values

    2. Deploy:
       docker-compose up -d

    3. Access:
       Frontend: http://localhost:3000
       API:      http://localhost:3001
